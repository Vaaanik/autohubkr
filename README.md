# АвтоХаб — автомобильное сообщество Кривого Рога

Сайт [autohubkr.com](https://autohubkr.com) и веб-приложение [autohubkr.com/app/](https://autohubkr.com/app/) для водителей и автосервисов (СТО). Пилотная версия, закрытый тест.

- **Водитель** ведёт гараж: авто, пробег, документы и их сроки, история обслуживания, паспорт авто для продажи. Отправляет заявку в СТО, смотрит цены по городу и свободные окна со скидкой, получает напоминания в Telegram.
- **СТО** получает заявки, ведёт журнал работ и прайс, публикует свободные окна, видит отчёт по своему району и автоматически напоминает клиентам о ТО и сезонной смене шин.
- **Администратор** модерирует сервисы, видит заявки, анкеты, переходы и настройки сервера.

## Как устроено

```
Браузер ──► GitHub Pages (статика: сайт и приложение)
   │
   └──► Supabase Edge Function «api» ──► PostgreSQL (таблицы закрыты RLS)
              │                       └► Storage (фото)
              ├──► Telegram Bot API (вход, уведомления, мини-приложение)
              ├──► Google Gemini (AI-подсказки)
              ├──► TurboSMS / Telegram Gateway (коды подтверждения)
              └──► Google Apps Script (отправка писем)
GitHub Actions ──► ежедневные напоминания и ежемесячный импорт реестра VIN
```

- **Фронтенд** — обычные файлы без сборки, хостинг GitHub Pages из ветки `main`, домен в `CNAME`.
- **Сервер** — одна Edge Function `api` в проекте Supabase `autohubkr` (регион West EU, Paris). Вход по телефону и PIN-коду (хранится только хеш), проверка JWT в Supabase отключена: авторизация своя.
- **База** — PostgreSQL. На всех таблицах включён RLS без политик: напрямую из браузера их прочитать нельзя, доступ только через функцию с сервисным ключом.

## Настройки сайта

Все значения — в `assets/config.js`, менять только то, что в кавычках:

- `formEndpoint`, `appEndpoint` — адрес функции Supabase, куда уходят анкеты, переходы и запросы приложения.
- `tgBot` — имя Telegram-бота без `@`. Обычно пусто: сервер определяет его сам.
- `tgDrivers`, `tgServices` — ссылки на Telegram-группы водителей и сервисов (в футере и после заявки).
- `driversTotal`, `servicesTotal` — сколько мест в тесте.
- `driversTaken`, `servicesTaken` — занятые места вручную; `null` — число берётся из базы.
- `counterMin` — порог, с которого показывается счётчик (обычно задаётся в админке → «Настройки»).
- `fx` — анимации на страницах; `false` отключает их.

Источник переходов отмечается меткой в ссылке: `https://autohubkr.com/?s=tg_vodii_kr` (подходят и `utm_source`). Метка сохраняется на весь визит и попадает в анкету. Учёт без cookies и сторонних сервисов.

## Сервер (Supabase Edge Function)

### Код и деплой

1. Править только `supabase/functions/api/core.js` (логика API) и `server.part.ts` (подключение к Supabase, Telegram, почте).
2. Запустить `sh supabase/build.sh` — он соберёт `supabase/functions/api/index.ts`. Сам `index.ts` руками не редактировать.
3. Открыть в панели Supabase: Edge Functions → `api` → вставить содержимое `index.ts` → **Deploy**.
4. Закоммитить исходники вместе с пересобранным `index.ts`, чтобы они не расходились.

### Секреты функции

Задаются в панели Supabase: Edge Functions → Secrets. Ключи Supabase платформа передаёт сама. Какие секреты подключены, видно в приложении: админка → «Настройки».

| Секрет | Для чего |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Telegram-бот: регистрация, переход из анкет, уведомления, мини-приложение |
| `GEMINI_API_KEY` | AI: подсказка неисправности, распознавание чеков и полисов, описание авто |
| `GEMINI_MODEL` | Необязательно: конкретная модель Gemini (иначе автовыбор) |
| `AUTO_RIA_KEY` | Модификации, комплектации и рыночная цена авто |
| `RELAY_SECRET` | Письма сервисам через Google Apps Script (тот же секрет в свойствах скрипта) |
| `TG_GATEWAY_TOKEN` | Коды подтверждения номера в Telegram |
| `TURBOSMS_TOKEN` | Коды подтверждения по SMS |
| `TURBOSMS_SENDER` | Имя отправителя SMS, зарегистрированное в TurboSMS |
| `TURBOSMS_VIBER_SENDER` | Отправитель Viber: сначала Viber, потом SMS |

После добавления `TELEGRAM_BOT_TOKEN` нажмите в админке «Налаштувати Telegram-бота» — сервер сам зарегистрирует вебхук и узнает имя бота.

### База данных

- Полная схема: `supabase/schema.sql`. Отдельно: гараж и фото (`garage.sql`), анкеты и переходы (`leads.sql`), реестр VIN (`vin-registry.sql`).
- Миграции `supabase/migrate-ГГГГ-ММ-ДД-*.sql` выполняются по порядку дат в SQL Editor. Все написаны так, что повторный запуск ничего не ломает.
- Фото: бакет `car-photos` — приватный (ссылки подписываются на 7 дней), `sto-photos` — публичный (фото сервисов для каталога).
- Назначить администратора: в SQL Editor выполнить
  `update users set role = 'admin' where phone = '+380…';`
  и войти в приложение заново.

## Автоматические задачи (GitHub Actions)

Нужен секрет репозитория `SUPABASE_SERVICE_KEY` (Settings → Secrets and variables → Actions).

| Файл | Когда | Что делает |
|---|---|---|
| `daily.yml` | Каждый день ~09:23 по Киеву | Напоминания водителям о сроках документов (за 30, 7 и 1 день), напоминания клиентам от СТО о ТО и шинах; 1-го числа — отчёт «ваш район» сервисам |
| `vin-registry.yml` | 20-го числа каждого месяца | Обновляет таблицу `vin_registry` из открытого реестра МВС на data.gov.ua. Можно запустить вручную: регион и режим «только посчитать» |
| `vin-check.yml` | Вручную | Проверяет, есть ли конкретный VIN в данных МВС. Ничего не записывает |

Репозиторий публичный, поэтому логи задач видны всем. Задачи выводят в лог только счётчики, без данных пользователей — при изменениях это нужно сохранить.

## Письма

Письма отправляет Google Apps Script из `app-backend/Api.gs`, развёрнутый как веб-приложение (адрес — `MAIL_RELAY` в `server.part.ts`). Остальная его логика отключена (`MIGRATED = true`).

- `relay.notify` — уведомление администратору (новая анкета, СТО, заявка). Письмо уходит владельцу скрипта; другой адрес можно задать свойством скрипта `ADMIN_EMAIL`.
- `relay.mail` — письмо сервису, работает только с секретом `RELAY_SECRET` (в свойствах скрипта и в секретах Supabase).
- Ограничение — 60 писем в час на каждое действие.

После изменения `Api.gs`: вставить код в редактор Apps Script → «Розгорнути» → «Керувати розгортаннями» → карандаш → «Нова версія». Адрес не меняется.

Рассылка приглашений сервисам — `outreach/mailer.gs`, запускается из меню «АвтоХаб» в своей Google Таблице, письма уходят с `info@autohubkr.com`.

## Публикация и домен

- GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.
- Домен `autohubkr.com` указан в `CNAME`. Если переносить: у регистратора четыре записи **A** на `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` и **CNAME** для `www` на `vaaanik.github.io`, затем включить **Enforce HTTPS**.

## Безопасность

- **Не коммитить** ключи, токены, личные почты и телефоны, ссылки на Google-таблицы с данными. Всё секретное — только в секретах Supabase, GitHub Actions и свойствах Apps Script.
- Адрес функции Supabase и ссылки на Telegram-группы открыты намеренно: они и так видны на сайте.
- Телефон водителя сервис видит только после того, как принял заявку.
- В коммитах использовать анонимную почту GitHub (Settings → Emails → «Keep my email addresses private»).

- `scripts/archive-build-sto-pages.mjs` — генератор страниц каталога СТО для поисковиков. Каталог `/sto/` убран с сайта, скрипт оставлен на случай возврата.
