# АвтоХаб: сайт автомобільної спільноти Кривого Рогу

Сайт из трёх страниц, без сборки и серверной части. Всё работает как обычные файлы.

| Страница | Адрес на сайте | Файл |
|---|---|---|
| Главная (выбор: водитель или сервис) | `/` | `index.html` |
| Для водителей | `/drivers/` | `drivers/index.html` |
| Для сервисов | `/services/` | `services/index.html` |

Общие стили лежат в `assets/site.css`, **все настройки в одном файле `assets/config.js`**.

## 1. Подключить отправку заявок в Google Таблицу

Таблица «АвтоХаб: заявки» уже создана в вашем Google Диске, на ней два листа: «Водії» и «Сервіси».
Её адрес: https://docs.google.com/spreadsheets/d/1w3cLJ2JYqvrKXGb0CzehgGXA2PNPD7viHpHu4FI7cng

1. Откройте эту таблицу, в меню выберите **Розширення, Apps Script**.
2. Удалите всё, что там есть, и вставьте весь текст файла `apps-script/Code.gs`.
3. Скрипт работает только с этой таблицей. О каждой новой заявке он присылает письмо на адрес из `NOTIFY_EMAIL` (сейчас malykhinivan8@gmail.com). Чтобы отключить письма, оставьте там пустые кавычки. Лимит Gmail: около 100 писем в сутки.
4. Нажмите **Розгорнути, Нове розгортання**, тип **Веб-застосунок**.
   - Виконувати від імені: **Я**
   - Хто має доступ: **Усі**
5. Подтвердите доступ (Google спросит разрешение для вашего же скрипта, это нормально).
6. Скопируйте адрес веб-приложения (заканчивается на `/exec`) и вставьте в `assets/config.js` в поле `formEndpoint`.
7. Проверка: откройте адрес `/exec` в браузере, должно быть написано `OK`. Затем отправьте тестовую заявку с сайта и убедитесь, что строка появилась в таблице.

Если после изменения кода скрипта заявки перестали приходить: **Розгорнути, Керувати розгортаннями, Редагувати, Нова версія**. Адрес при этом не меняется.

> Пока `formEndpoint` пустой, на настоящем сайте форма покажет ошибку и не будет делать вид, что заявка принята. Тестовый режим без отправки работает только при открытии файла с компьютера или на localhost.

## 1а. Учёт переходов

Каждая страница сайта отправляет просмотр в лист «Переходи» (скрипт `assets/track.js`, без cookies и сторонних сервисов). Итоги считает лист «Зведення»: всего просмотров, уникальные посетители, по дням и по источникам, сколько заявок пришло с каждого источника.

Чтобы видеть, откуда пришли люди, давайте в каждый канал свою ссылку с меткой `?s=`:
`https://autohubkr.com/?s=tg_vodii_kr` — метка сохраняется на весь визит и попадает в заявку. Подходят и обычные `utm_source`.

Бот Telegram, который строит превью ссылки, JavaScript не выполняет и в переходы не попадает.

## 2. Telegram-группы и лимиты мест

В `assets/config.js`:
- `tgDrivers` и `tgServices` — ссылки на закрытые Telegram-группы. Человек видит кнопку на них после заявки.
- `driversTaken` и `servicesTaken` — настоящее число занятых мест. Пока стоит `null`, счётчик на странице скрыт. Не ставьте выдуманные числа.

## 3. Публикация на GitHub Pages

1. В репозитории: **Settings, Pages**, Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
2. Через минуту сайт откроется по адресу `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`. Все ссылки на страницах относительные, поэтому работает и так, и на своём домене.
3. Репозиторий должен быть публичным (на бесплатном тарифе). В нём нет секретов: адрес веб-приложения `/exec` и так виден на сайте.

## 4. Свой домен

1. В репозитории: **Settings, Pages, Custom domain**, впишите домен, например `autohub.com.ua`. GitHub сам создаст файл `CNAME`.
2. У регистратора домена в DNS добавьте:
   - для основного домена (apex) четыре записи **A** на `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - (по желанию) четыре записи **AAAA** на `@`: `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`
   - для `www` запись **CNAME** на `ИМЯ.github.io` (без названия репозитория)
3. Подождите, пока GitHub проверит DNS (от минут до часов), и включите **Enforce HTTPS**.
4. Рекомендуется подтвердить домен в **Settings, Pages**, чтобы его не мог занять кто-то другой.

## 5. Что обязательно сделать до рекламы

- Добавить на сайт страницу с политикой конфиденциальности и ссылку на неё в согласии. На сайте собираются персональные данные.
- Убедиться, что вы готовы выполнять то, что обещано на страницах: заявки без комиссии на старте, ответ сервисам за 1–2 дня, удаление заявки по просьбе.
- Проверить перечень открытых баз, который будет использоваться для проверки авто. Пока страница честно пишет, что состав проверок зависит от доступности данных.

## 6. Приложение (MVP) — autohubkr.com/app/

Пилотное веб-приложение: водитель добавляет авто, создаёт заявку в выбранное СТО, видит ответ, историю ремонтов и оставляет отзыв. У СТО есть кабинет с заявками (принять, отклонить, в работе, завершить) и профиль сервиса. Приложение ставится на телефон как обычное (меню браузера → «Добавить на главный экран»).

- Интерфейс: `app/index.html` (одна страница, без сборки), иконки и `sw.js` для установки.
- Сервер: `app-backend/Api.gs` — Apps Script, привязанный к таблице «АвтоХаб MVP: дані застосунку». Адрес развертывания `/exec` записан в `assets/config.js` → `appEndpoint`.
- Вход: телефон + PIN (4–6 цифр). PIN хранится только как хеш. Забытый PIN: удалите строку пользователя на листе «Користувачі», и человек зарегистрируется заново.
- **Модерация СТО:** новый сервис не виден водителям, пока на листе «СТО» в колонке «Активний» не стоит TRUE. О каждой новой регистрации СТО и каждой заявке приходит письмо.
- Телефон водителя сервис видит только после того, как принял заявку.
- После изменения `Api.gs`: «Начать развертывание → Управление развертываниями → карандаш → Новая версия». Адрес не меняется.
